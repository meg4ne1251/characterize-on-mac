# MotionBuilder の既存スクリプト

現在 MotionBuilder で使っているスクリプトを、このディレクトリへ追加します。macOS 向けの実装を検討するための参照資料として管理します。

元の処理を確認できるよう、最初は使用中の内容をそのまま保存してください。複数ある場合は、処理や用途が分かるファイル名にします。

分かる範囲で、スクリプトと一緒に以下をメモしてください。

- 使用している MotionBuilder のバージョン。
- 実行方法と実行順序。
- 想定するボーン名、名前空間、実行前のシーンの状態。
- 必要な追加ファイルや外部モジュール。
- 処理後にどのような状態になるか。

ここへ追加したスクリプトは参照用です。macOS 向けの実装と、必要な置き換え処理は `src/` に作成します。
