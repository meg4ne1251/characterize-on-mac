# MotionBuilder 側の検証スクリプト

MotionBuilder 内で実行する公開用の診断・検証スクリプトの追加先です。現在、実行用スクリプトは同梱していません。macOS 向け CLI の実装は `src/characterize/` にあります。

スクリプトを追加する場合は、以下を記録してください。

- MotionBuilder のバージョンと実行方法。
- 想定するボーン名・名前空間・実行前のシーンの状態。
- 必要な追加ファイルや外部モジュール。
- シーンを書き換えるかどうかと、確認できる結果。

個人の絶対パスや非公開の資料・既存スクリプトは含めず、ローカル参照資料は Git 対象外の `tmp/` に置いてください。モデル・画像は Git 対象外の `data/` に置きます。
