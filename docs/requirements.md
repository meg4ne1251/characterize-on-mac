# 要件と現在の状態

## 目的

サークルの VLLModelConfigure2 2025.2 が MotionBuilder 内で行う規格化を、Maya のライセンスに依存せず macOS と Autodesk FBX SDK で実行すること。キャラクタライズに加え、命名、テクスチャ、グループ、各種チェックと助言まで対象とします。追加要件として、AポーズからTポーズへの自動補正も扱います。

## 実装と検証

- [元スクリプトとの機能対応](source-analysis.md)
- [SDK・実行方法・対応範囲](setup.md)
- [実モデルと自動テストの結果](validation.md)

実装言語は C++17、起動・ビルド・検証用スクリプトは Python です。GUI は現時点では実装していません。

FBX SDK 2020.3.11 で入出力し、提供された処理前モデル5件について規格化とTポーズ補正を実行します。入力のハッシュ、出力の再読み込み、頂点・シェイプ・UV・ウェイト・バインド行列の保持を検査します。

## 最終互換性の確認に残っている項目

- 出力 FBX を MotionBuilder で開き、Character が正しく有効になっていること。
- HIK によるリターゲットで、腕・脚・指が意図通り動くこと。
- Tポーズに関する MotionBuilder の警告と、モデルごとの肩・手首・接地・服の変形。
- SelectionSet が元スクリプトの FBGroup と同じ操作・表示を提供するか。
- Flat / Lighted など MotionBuilder 固有のシェーダー・Viewer 設定の扱い。
- HIK Template の実物を用いた出力・読み込みの互換性検証（元スクリプトも出力自体は行いません）。

これらを確認するまで「サークルのツールと完全に同じ結果」とは扱いません。実行結果にも `motionbuilder_verified: false` を明示します。

## 今後拡張する場合

- ファイルと画像フォルダを選べる GUI。
- Intel Mac・別 macOS バージョンでの検証。
- アニメーション付きモデル、拘束、非一様スケールへの対応。
- 手首・指・肩の形状を含むモデルごとの補正、足裏の接地。
- 任意の命名・複数キャラクタの明示的な選択。
