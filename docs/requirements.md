# 要件と現在の状態

## 目的

FBX モデルの規格化を、Maya のライセンスに依存せず macOS と Autodesk FBX SDK で実行すること。キャラクタライズに加え、命名、テクスチャ、グループ、各種チェックと助言まで対象とします。AポーズからTポーズへの自動補正も扱います。

## 実装と検証

- [実装の設計と互換性](source-analysis.md)
- [SDK・実行方法・対応範囲](setup.md)
- [実モデルと自動テストの結果](validation.md)

実装言語は C++17、起動・ビルド・検証用スクリプトは Python です。GUI は現時点では実装していません。

FBX SDK 2020.3.11 で入出力し、処理前モデル5件を使って規格化とTポーズ補正を検証しています。入力のハッシュ、出力の再読み込み、頂点・シェイプ・UV・ウェイト・バインド行列の保持を検査します。画像の欠落や UV の不整合があるモデルは出力を停止します。

## 最終互換性の確認に残っている項目

- 出力 FBX を MotionBuilder で開き、Character が正しく有効になっていること。
- HIK によるリターゲットで、腕・脚・指が意図通り動くこと。
- Tポーズに関する MotionBuilder の警告と、モデルごとの肩・手首・接地・服の変形。
- SelectionSet が MotionBuilder の FBGroup と同じ操作・表示を提供するか。
- Flat / Lighted など MotionBuilder 固有のシェーダー・Viewer 設定の扱い。
- HIK Template の実物を用いた出力・読み込みの互換性検証（本ツールはテンプレート出力を行いません）。

これらを確認するまで、MotionBuilder 上の処理との完全互換は保証しません。実行結果にも `motionbuilder_verified: false` を明示します。

## 今後拡張する場合

- ファイルと画像フォルダを選べる GUI。
- Intel Mac・別 macOS バージョンでの検証。
- アニメーション付きモデル、拘束、非一様スケールへの対応。
- 手首・指・肩の形状を含むモデルごとの補正、足裏の接地。
- 任意の命名・複数キャラクタの明示的な選択。
